التاريخ المرجعي: 2026-10-31. **الحالة: تنفيذ جزئي قابل للمراجعة، غير جاهز للإنتاج.**

المشروع الحالي: `QMR7S/Q7Farmakon`. الفرع الجديد: `feature/q7-v24-work-development`، مبني على `feature/q7-v23-owner-player-2026-10-31` عند `02005bf90d9151c3c06ff104a902b7935e4035ba`. لم يحدث دمج أو نشر أو تعديل بيانات Supabase أو تفعيل خدمة مدفوعة.

## المراجعة ومصدر الهوية

قُرئ أمر التنفيذ والمواصفات V2.4 بالكامل، وجُردت مسارات المشروع ومكوناته ووثائق أمان V2.3 وبوابة الاستحقاق وSQL المرجعي. المستودع أساس صغير، وليس منصة مكتملة مخفية عن الواجهة. الألوان الفعلية في CSS الدخول: `#2447B5`, `#1A3590`, `#F4F7F5`, `#FFFFFF`, `#DCEBE3`, `#14232B`. استُخدمت هذه الهوية، دون ادعاء توفر صورة الدخول الأصلية أو مطابقة مرجع بصري غير موجود في المستودع. لا يوجد شعار تصويري رسمي أو أغلفة كورسات فعلية؛ علامة F طباعية، وأيقونات الكورسات حيادية لا تدعي أنها أغلفة رسمية.

## المنجز في الشيفرة

- إصلاح خطأ محرف `\\n` في إجراء المالك، وإغلاق JSX غير مطابق في اللوحة السابقة، وأخطاء TypeScript لوسائط كوكيز Supabase.
- تشغيل آمن دون أسرار: الواجهة لا تنهار عند غياب إعداد Supabase؛ العمليات الحساسة تظل مرفوضة. إزالة عنوان/مفتاح مشروع قديم من مثال البيئة حتى لا يُستخدم تلقائياً بالخطأ.
- واجهة طالب مشتركة، Sidebar قابلة للطي، رأس صغير، خمسة عناصر هاتف بالترتيب المطلوب، safe-area، رابط تجاوز للمحتوى، focus، reduced-motion، تصميم Light/Dark وRTL/LTR.
- صفحة رئيسية بأولوية الدخول للكورسات، أقسام تعلّم/تدريب/مكتبة وخطة يوم إرشادية لا تدعي وجود خطة شخصية أو نسب تقدم. لا طلاب أو اشتراكات أو إحصاءات مختلقة.
- شاشات مستقلة: كورساتي، التعلم، البحث في قائمة الكورسات المنشورة، المكتبة بأقسامها الأربعة، البنك العام، البنك الوزاري، الحالات، AI، الملاحظات، المحفوظات، التنزيلات، الخطة، التحليلات، الاشتراكات، الإشعارات، الإعدادات، المساعدة، الخصوصية، الشروط والتثبيت. الشاشات التي لا تملك خدمة بيانات تعرض عدم الاتصال/عدم التهيئة صراحةً؛ وجود الشاشة لا يعني اكتمال وظيفتها.
- تسجيل دخول/إنشاء حساب متناسقان مع الهوية، ودخول Google للمالك مع فحص الخادم الموجود. لم تتم تهيئة OAuth في حساب المستخدم.
- قراءة الكورسات المنشورة واشتراكات الطالب الفعالة عند توفر الجداول. إصلاح التعامل مع الاشتراك الدائم وحالة active وتاريخ الانتهاء. صفحة الكورس تربط المحاضرات بمركزها. بوابة الميديا تبقى المرجع الأمني المستقل؛ شارة الواجهة لا تمنح وصولاً.
- مركز محاضرة حقيقي `/lessons/:id`: يطلب رابط الميديا من البوابة ويعرض موارد المدرس وPDF والملاحظات وAI بحالة التهيئة الفعلية. لا تفريغ كلام أسفل الفيديو ولا فيديو عينة يحل محل محاضرة خاصة.
- المشغل: تحكم تشغيل/إيقاف وسحب وصوت وسرعة 0.5–2x، خطوة 5/10/15 ثانية، قائمة زجاجية داخلية، جودات وترجمات من الملفات الممررة فقط، Escape وإغلاق خارجي، اختصارات عند تركيز الإطار، fullscreen/PiP حسب الدعم، إخفاء التحكم أثناء التشغيل، واستعادة الموضع عند تبديل الجودة. اختُبر التشغيل فعلياً بملف اختبار محلي، كما هو موثق أدناه؛ لم يُختبر بث كورس محمي.
- `/media-lab`: اختبار تقني معلن بملف فيديو وVTT محليين دون رفع أو حفظ. لا يساوي نظام تنزيل محمي أو تحققاً من التشغيل على Android/iOS.
- مسار `/api/study/:lessonId` للملاحظات الخاصة والتوقيت وصفحة PDF: هوية خادمية، no-store، قيد مستخدم صريح، تحقق مدخلات، رفض origin مختلف، وcompare-and-swap للنسخ القديمة HTTP 409. واجهة حفظ تلقائي للملاحظات مع حالة فشل/تعارض؛ لا تخزين محلي غير مشفر للملاحظات الخاصة. SQL للمراجعة فقط مع RLS بدون وصول المدرس للملاحظات.
- لوحة مالك ثنائية اللغة بتفضيلات مشتركة وأقسام واضحة، إنشاء مسودة كورس وإصدار كود عبر الإجراءات المحمية الموجودة، معاينة عنوان دون حفظ، إحصاءات من بيانات فعلية أو Unknown، وعدّ مشتركين فريدين وحالة active فقط. الأقسام غير المربوطة موسومة. `/owner-review` يعرض واجهة خالية فقط؛ لا يتجاوز المصادقة ولا يجلب بيانات المالك.
- حارس بيئة يشترط تطابق URL مع مرجع Staging محدد قبل الكتابة أو توقيع الميديا، مع رفض Vercel production. حماية no-sniff/referrer/permissions، فصل مخرجات HMR عن build، تثبيت نسخ الاعتماديات وlockfile، وCI للفحص فقط دون نشر أو أسرار.
- `/review`: يعرض صفحات التطبيق نفسها داخل iframe بعروض القبول الخمسة وخيارات اللغة والمظهر. هذه أداة للفحص وليست دليلاً على اجتياز المقاسات.

## اكتشاف Staging — قراءة فقط

المشروع المتصل باسم Farmakon-Staging ومرجعه `qfzharpouemueipsrduv` أعاد `public.tables=[]` عند الفحص. لم يُنشأ جدول أو حساب أو bucket أو منحة، ولم تُنسخ بيانات الإنتاج. عنوان مثال البيئة السابق لا يطابق المشاريع التي أظهرها الاتصال المتاح. لذلك لا يوجد دليل كافٍ أن قاعدة Staging المتاحة هي قاعدة Q7 المقصودة؛ لم نربطها تخميناً. إنشاء مشروع/فرع جديد قد يرتبط بتكلفة، فلم تُفعّل خدمة مدفوعة.

يلزم تأكيد مشروع Q7 المعزول، فحص مخطط courses/units/lessons/enrollments وRLS، ثم مراجعة SQL وتطبيقه واختباره هناك. لا تطبق ملفات docs/sql على production.

**المعاينة الحالية:** `http://terminal.local:4173/`، ومراجعة الصفحات: `http://terminal.local:4173/review`. رابط داخلي لجلسة Work، وليس موقعاً عاماً أو رابط إنتاج دائم.

### اختبار المشغل

ملف اختبار مولد محلياً باستخدام ffmpeg، 640×360، مدته 18 ثانية؛ ليس محتوى محاضرة. اختُبر عبر `/media-lab` دون رفع إلى خادم. الدليل المقاس: readyState=4، paused=false، تقديم من نحو 0.35 ثانية إلى 11.06، playbackRate=1.5، ثم إيقاف عند نحو 1.60 بعد إعادة المؤشر للبداية. أضيف VTT محلي وحالته readyState=2 ومسار الترجمة showing. اختيرت الخيارات من القائمة الزجاجية عبر نقرات فعلية.

الصورة `docs/qa/player-local-test.jpg` تظهر القائمة وملف الاختبار والترجمة وPlaying in picture-in-picture، وكذلك رسالة عدم دعم ملء الشاشة في هذا المتصفح. لا تعني هذه التجربة نجاح تبديل جودات متعددة أو تجديد signed URLs أو Offline أو اختبارات Android/iOS.

الصورة `docs/qa/home-en-dark.jpg` للواجهة النهائية الإنجليزية الداكنة. لا توجد مجموعة صور قبل/بعد كاملة لكل المقاسات؛ الصورة الأولية شوهدت فقط في أداة المتصفح. بعض محاولات التقاط iframe أعادت صورة بيضاء قبل الرسم وتم استبعادها من الدليل.
